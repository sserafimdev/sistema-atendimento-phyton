# Sistema de Atendimento

Projeto de terminal desenvolvido em Python para praticar lógica de programação e organização de dados.

## Funcionalidades
- Cadastro de clientes e solicitações
- Listagem dos atendimentos
- Atualização de status: aberto, em andamento e concluído

## Como executar
1. Tenha o Python 3 instalado.
2. Abra o terminal na pasta do projeto.
3. Execute: `python main.py`

Os dados ficam armazenados em memória durante a execução do programa.
